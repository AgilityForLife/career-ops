## Role Summary

Anthropic is hiring a Technical Program Manager to scale the API platform stack, sitting at the intersection of API services and infrastructure (compute, databases, networking, inference). The role requires driving cross-functional program execution for API features and platform enhancements that serve Anthropic's growing developer ecosystem. This is a deeply technical TPM role where the program manager must understand API architecture, inference infrastructure, and platform scaling.

## Key Gaps

- API platform scaling requires understanding of API design, rate limiting, authentication, developer experience, and service reliability at massive scale — all outside the candidate's demonstrated experience
- Inference infrastructure (GPU compute, model serving, latency optimization) is a specialized domain with no overlap in the candidate's background
- The "intersection of API and infrastructure" framing means this is a deeply technical role where the TPM needs to make or inform architectural trade-offs
- Only 2 CS clearly engaged — similar profile to the Cloud Inference role (Report 041) which also scored 3.2/5
- Developer-facing platform product management is a different context than enterprise internal program delivery
- Competitive applicant pool will include candidates with API platform and infrastructure program management experience at FAANG-scale

## Compensation Assessment

Estimated $290-365K total compensation dramatically exceeds the $130-150K target. As with other Anthropic roles, this represents a 2-2.5x multiplier on target comp. The compensation premium reflects the technical depth expected in the role.

## Recommendation

**PREPARE ONLY, low priority**

The API/inference infrastructure domain wall is material. While CS-1 (program delivery) and CS-5 (cross-functional stakeholder alignment) transfer, the technical depth bar for this role is high. The TPM needs to understand API architecture, inference scaling, compute resource management, and platform reliability — areas where the candidate has no demonstrated experience.

This role is less defensible than the Databases role (Report 055) where CS-2 provides a genuine technical bridge. If the candidate is choosing among Anthropic roles to prepare for, the Databases role should take priority.

If proceeding despite the lower priority:
1. Frame Verisk enterprise platform delivery as analogous to platform scaling programs
2. Emphasize the coordination complexity across multiple technical domains
3. Acknowledge the API/inference domain as a growth area while positioning delivery governance as the transferable superpower
